## 你需要填写/准备的东西
1. Supabase：新建项目→执行 `supabase/migrations/0001_init.sql`→取 URL 与 anon key（docs/SETUP.md）。
2. 高德：Android Key(包名 `com.couple.couple_locator` + SHA1)、iOS Key(Bundle ID `com.couple.coupleLocator`)、Web 服务 Key（docs/AMAP.md）；可选自定义样式文件。
3. `env/dev.json`（参考 `env/example.json`）；GitHub Actions 里配 Secrets（docs/BUILD.md）。
4. Android 发布签名：`scripts/gen_keystore.sh`，自己保管。

## 已知限制
- **iOS 后台**：App 被用户上划杀掉后不会再被唤醒；无 APNs，被系统终止时收不到 Realtime 推送，只能靠显著位置变化唤醒后补拉事件（docs/IOS_SIDELOAD.md）。
- **iOS 小组件侧载**：免费 Apple ID 重签可能因 App ID 额度/App Group 不支持而失败，请改用 noext 包。
- **Supabase 国内访问**：新加坡/东京区域在部分网络下延迟高或不稳；位置会先存本地再补传。
- **高德 Key**：Android 调试/发布 SHA1 不同需分别申请；地图样式文件需自行在控制台生成。
- **服务器可见的明文**：心跳时间戳与暂停标记、用户 id/couple id/各记录时间戳（有意取舍，见 docs/SECURITY.md）。
- **本地缓存**：本机 SQLite 中缓存的是解密后的坐标，未做数据库级加密。
- **TOFU**：公钥由服务器分发，首次配对后需当面核对安全码才能防中间人。
- **国产 ROM 保活**：无法通过代码保证；必须按引导页完成自启动/省电/锁定设置。
- **phosphor_flutter**：官方 2.1.0 与新版 Flutter 不兼容，已在 `packages/phosphor_flutter` 内置补丁版。
