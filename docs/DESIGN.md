# 视觉与交互设计规范

> 关键词：温暖、轻盈、会呼吸。地图永远是主角，界面像漂浮在地图上的彩色糖纸。

## 1. 色彩

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg` | `#FFF8F3` 奶油白 | `#1A1625` 暗紫蓝 | 页面背景 |
| `surface` | `#FFFFFF` | `#241E33` | 卡片底 |
| `surfaceGlass` | `#FFFFFF` @72% | `#2A2340` @68% | 毛玻璃卡片 |
| `ink` | `#2D2238` | `#F7F1FF` | 主文字（对比度 ≥ 12:1） |
| `inkSoft` | `#6B5E78` | `#C9BEDB` | 次文字（≥ 4.5:1） |
| `accentText` | `#C7365A` | `#FF8FA8` | 强调文字（≥ 4.5:1） |
| `onGradient` | `#3A1030` | `#3A1030` | 渐变按钮上的文字（≥ 4.5:1，避免白字在珊瑚色上不达标） |
| `mint` | `#4ADEB4` | 同 | 在线 / 充电 / 安全 |
| `sky` | `#5CC8FF` | 同 | 网络 / 信息 |
| `grape` | `#A78BFA` | 同 | 图表 / 分类 |
| `danger` | `#FF4D6D` | `#FF6B85` | 低电量 / SOS |

主渐变 `sunrise`：`#FF6B8A → #FF9A6C → #FFD166`（135°），用于主按钮、顶部背景、强调。
对比度由 `test/core/contrast_test.dart` 自动校验。

| sky | 天空气泡 | `#5CC8FF → #A78BFA` |
| grape | 葡萄果冻 | `#A78BFA → #FF6B8A` |

## 2. 形状与质感
- 卡片圆角 24，小组件圆角 16，按钮全胶囊。
- 阴影：彩色弥散 `BoxShadow(color: 主色@28%, blur 24, offset (0,10))`，深色模式降到 @18%，不用黑色硬阴影。
- 毛玻璃：`BackdropFilter(blur 18)` + `surfaceGlass` + 1px 白色@40% 描边。所有叠在地图上的面板（顶部状态条、底部抽屉、对方卡片）都用毛玻璃。
- 图标：Phosphor（Regular 线性为主，选中态用 Fill），圆润。
- 字体：标题/数字用打包的「站酷快乐体 ZCOOL KuaiLe」，正文用系统中文字体。

## 3. 动效
| Token | 时长 | 曲线 |
|---|---|---|
| `fast` | 200ms | easeOutCubic |
| `normal` | 300ms | `springOut`（easeOutBack 0.9 overshoot） |
| `slow` | 400ms | easeInOutCubicEmphasized |

- 系统开启「减弱动态效果」（`MediaQuery.disableAnimations`）时：时长归零、关闭光斑/呼吸/粒子，仅保留淡入。
- 按钮按下缩放到 0.94，松开弹簧回弹 + `HapticFeedback.lightImpact`。
- 列表项错峰 40ms 依次从下 16px 淡入。
- 数字（距离、电量、统计）用滚动计数 `RollingNumber`。
- 页面转场：头像使用 `Hero`；路由用淡入 + 上移 24px 的弹簧过渡。
- 首页（非地图页，如「我的」「互动」）背景有 3 个缓慢漂移的彩色光斑 `FlowingBlobs`，地图页关闭以保性能。

## 4. 地图
- 高德自定义样式：浅色清新，水体 `#BDEFF0`，绿地 `#D8F5E6`，道路白色，减少 POI 标注（在高德控制台生成后放入 `assets/map_style/`）。
- 头像标记（原生 Marker 位图，由 `AvatarMarkerPainter` 绘制）：
  - 直径 56 的圆形头像（emoji 或照片），外环 5px 个人渐变，白色 2px 内描边；
  - 下方 10px 小三角指针，颜色取渐变末端；
  - 电量 < 15% 时右上角红色 `danger` 电池徽标；暂停共享时整体去饱和 + 灰色「暂停」徽标。
- 呼吸光晕：Flutter 覆盖层（`BreathingHalo`），以个人色 @30% 在 1.0–1.6 倍半径之间 2.4s 循环，通过 `toScreenCoordinate` 定位，不拦截手势。
- 两人之间：个人色虚线 + 毛玻璃距离气泡（`1.2 km`，滚动计数）。距离 < 100m 时触发心形粒子 `HeartBurst`。
- 位置更新：800ms easeInOut 线性插值（经纬度），每 16–50ms 刷新一次 Marker。

## 5. 页面布局
底部导航：毛玻璃胶囊悬浮 TabBar，4 Tab「地图 / 轨迹 / 互动 / 我的」，选中项渐变底 + Fill 图标 + 弹跳。

1. **引导页**：全屏 PageView，每页上半部分是自绘动画插图（定位雷达、月亮+定位针、铃铛摇摆、电池爱心、火箭自启动），下半部分标题 + 说明 + 渐变「去开启」按钮 + 「跳过」文字按钮；底部点状进度条随页弹性伸长。ROM 指引页按品牌 Chip 切换图文步骤。
2. **登录注册**：顶部 sunrise 渐变弧形背景 + 两个漂浮小头像插图；卡片内用户名/密码输入（胶囊输入框），登录/注册分段切换。首次登录进入资料设置：emoji 网格 / 相册、昵称、8 色主题色圆点选择。
3. **配对页**：两个 Tab 卡片「我来邀请」（大号 6 位邀请码滚动出现 + 二维码 + 10 分钟倒计时环）和「我有邀请码」（6 格验证码输入 + 扫码按钮）。配对成功全屏庆祝：两个头像从两侧飞入相撞冒爱心，随后展示安全码（4×5 数字分组）供核对。
4. **地图主页**：全屏地图；顶部毛玻璃状态条（对方头像 + 名字 + 「3 分钟前」+ 距离 + 共享开关胶囊）；右侧竖排三个圆形毛玻璃按钮（聚焦 TA / 两人视野 / 回到我）；底部大胶囊按钮「我到家了」（sunrise 渐变）+ 右侧红色 SOS 圆按钮（长按 3 秒环形进度）。
5. **对方详情卡**：点击标记上滑的毛玻璃底部抽屉：大头像（Hero）、状态图标动画（静止/步行/跑步/骑行/驾车）、电量环、网络、最后更新、按钮「戳一戳」「看轨迹」「导航过去」。
6. **轨迹回放页**：顶部横向周日历条（可展开月历），人物切换胶囊（我 / TA）；地图显示渐变折线；底部毛玻璃播放器：播放/暂停、1x/4x/16x 分段、可拖动进度条、当前时间。
7. **停留点列表**：轨迹页下拉抽屉中的时间轴：竖向渐变时间线，每个节点是地点名 + 时段 + 时长胶囊，点击后地图飞到该气泡。
8. **统计页**：本周/本月切换；顶部三张彩色卡（行走距离、在一起时长、最久停留地点），每周柱状图（两人双色），停留时长环形图。
9. **共同标记列表**：瀑布网格卡片（emoji 大图标 + 名称 + 备注 + 照片缩略图），右下悬浮「+」；编辑页底部抽屉。
10. **事件消息中心**：聊天气泡样式时间线，各自颜色气泡；到家事件带「收到」按钮；SOS 记录红色描边。
11. **SOS 全屏页**：红色径向脉冲（`SosPulse`）、大号「TA 需要帮助」、实时位置小地图卡、按钮「我知道了」「导航过去」「拨打电话」。发送方看到「SOS 进行中」+ 长按取消。
12. **设置页**：分组毛玻璃卡片列表：共享（上报档位分段控件、失联阈值滑块、保留期分段）、外观（主题色、深浅色）、隐私（密钥备份、清除数据）、关于（诊断日志：最近上报时间/失败原因）、危险区（解除配对、退出登录）。
13. **密钥备份页**：盾牌插图 + 说明；口令输入（两次）+ 强度条；两个按钮「备份到云端」「导出二维码」；恢复入口。

## 6. 事件动画
- **戳一戳**：8 种表情（❤️😘🤗👋🥺😆🌹🍬），对方头像处向上飘起 3–5 个放大旋转的 emoji，1.6s。
- **到家**：半屏卡片从底部弹出，房子 emoji 弹跳 + 彩带粒子。
- **SOS**：全屏红色，三圈向外扩散脉冲，0.8s 一次，伴随震动与铃声。
- **距离 < 100m**：心形粒子从两人中点向上飘散。
